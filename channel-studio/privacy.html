Privacy Policy

Channel Studio · last updated 26 September 2026

Summary

Channel Studio is a personal, single-user command-line tool that runs on my own computer. It has no server, no other users, and no analytics or tracking of any kind. It accesses one YouTube channel — mine — and shares nothing with any third party.

What the app accesses

When authorised, the app requests these Google OAuth scopes and uses them only as described:

ScopeWhat it is used for
youtube.upload Uploading videos the app has rendered to my own channel.
youtube.force-ssl Setting the title, description, tags and thumbnail of those videos, and posting the comment that accompanies them.
youtube.readonly Reading back the titles and publish dates of my own videos so performance data can be labelled.
yt-analytics.readonly Reading my own channel's performance data — views, watch time, average view duration and retention — to decide what to make next.

The app never reads, modifies or deletes content belonging to any other channel or user, and it does not request access to any Google service beyond YouTube.

What is stored, and where

  • OAuth tokens are written to a file on my own computer with owner-only permissions. They are never transmitted anywhere except to Google's own token endpoint.
  • Analytics data for my own channel is stored in a local SQLite database on the same machine.
  • Video files and metadata generated by the app are stored locally until they are uploaded to YouTube.

Nothing is stored on any server, and there is no hosted component to this application.

What is not done

  • No data is sold, rented or shared with third parties.
  • No data is used for advertising, profiling or training machine-learning models.
  • No personal data belonging to viewers is collected. Channel analytics are read only in the aggregated form YouTube provides.
  • There are no cookies, trackers or logs, because there is no website or server to run them.

Limited Use disclosure

Channel Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as it is useful to me and can be deleted at any time by removing the local files. Access can be withdrawn at any point from Google Account permissions, which immediately invalidates the app's stored tokens.
